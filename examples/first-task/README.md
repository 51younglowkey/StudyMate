# First task / 先用示例看看

This is a synthetic practice exercise. The course, requirements and project idea
are invented for demonstration; there are no real participants or findings.
For the exact sequence and user choices, read core `docs/USER_JOURNEY.md`,
section "当前示例模拟". The user may follow along, see an initial result or switch
to their own project. Start with a requirements map or question clarification,
then offer review/correction and minimal research planning. A later-stage
walkthrough explains prerequisites without inventing findings or test results.

第一次不想导入自己的资料时，可以说：

```text
先用 examples/first-task 中的合成示例看看。
结合课程要求和我的想法，给出对应关系、缺口和一个下一步。
```

Read only `course-brief.md` and `project-idea.md`. No personal workspace is
required merely to demonstrate an answer; do not create one without confirming
its title, slug and destination. Register synthetic source IDs in the answer:
EX-01 for the brief and EX-02 for the idea.

Expected first result: a small map of requirements to the proposed project work,
with source-section locators, unsupported assumptions and one proposed action.
The supported stage is framing/research planning: no research has been collected.
Use core `docs/PROJECT_FLOW.md`; do not start making the welcome-card prototype.
For example, the idea proposes a welcome card, while the brief asks for research
basis and a prototype learning question. Propose a way to examine that gap;
do not invent an interview, test result or confirmed project direction.

然后用户可以带自己的 brief、PPT、课程链接和需求，用同样的方式开始真实项目。
